# 📈 주식 백테스트

국내 주식·ETF와 미국 ETF를 **종목 검색 → 전략 선택 → 과거 성과 확인**까지 웹 화면에서 할 수 있는 백테스트 도구입니다.

- 시세: [FinanceDataReader](https://github.com/FinanceData/FinanceDataReader) (종목 목록 실패 시 [pykrx](https://github.com/sharebook-kr/pykrx))
- 엔진: [backtesting.py](https://github.com/kernc/backtesting.py)
- 화면: Streamlit(온라인 배포용) / Flask(내 PC용)

## 🌐 온라인으로 쓰기 (Streamlit Community Cloud, 무료)

GitHub Pages는 파이썬을 실행할 수 없어서, 이 저장소를 Streamlit Cloud에 연결해 실행합니다.

1. <https://share.streamlit.io> 접속 → **GitHub 계정으로 로그인**
2. **Create app** → **Deploy a public app from GitHub**
3. 입력
   - Repository: `kokott10-lang/stock`
   - Branch: `main`
   - Main file path: `streamlit_app.py`
   - (선택) App URL: 원하는 주소, 예) `kokott10-stock`
4. **Deploy** → 1~3분 후 `https://<주소>.streamlit.app` 에서 실행 (휴대폰에서도 접속 가능)

이후 이 저장소에 push 하면 앱이 자동으로 갱신됩니다.
무료 앱은 한동안 접속이 없으면 잠들고, 다시 열 때 깨우는 데 30초~1분 정도 걸립니다.

## 💻 내 PC에서 쓰기

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

- Streamlit 버전: `streamlit run streamlit_app.py` → 브라우저가 자동으로 열림
- Flask 버전: `python app.py` → <http://localhost:5000> 접속

> `templates/index.html` 을 더블클릭해서 열면 동작하지 않습니다. 반드시 위 명령으로 서버를 띄운 뒤 주소로 접속하세요.

## 기능

| 전략 | 내용 |
|---|---|
| 분할 익절 + 추적 손절 | 시작일 매수 → +1차% 일부, +2차% 일부 익절 → 1차 익절 후 고점 대비 -추적% 전량 매도, 진입가 대비 -손절% 전량 매도. 재진입 옵션: 청산 후 골든크로스 시 재매수 |
| 이동평균 골든/데드크로스 | 단기 이평이 장기 이평을 상향 돌파 시 매수, 하향 돌파 시 매도 |
| RSI 역추세 | RSI가 과매도선을 위로 넘으면 매수, 과매수선 이상이면 매도 |
| 매수 후 보유 | 비교 기준선 |

- 지수는 실제로 살 수 없으므로 **소수 단위로 사고판다고 가정**합니다(운용보수·배당 미반영). ETF가 생기기 전 시기(예: 1997 IMF 외환위기)를 볼 때 유용합니다.

### 포트폴리오 백테스트 (Streamlit 버전)

사이드바 **투자 방식 → 포트폴리오**에서 여러 자산을 비율대로 섞고 주기적으로 리밸런싱하는 경우를 계산합니다.

- **구성표**: 이름(코드를 넣으면 자동 표시) · 코드(종목코드·티커·지수코드, 현금은 `CASH`) · 비중(%). 이름이 잘리면 **ⓘ 구성 자세히**를 누르면 전체 이름이 뜹니다. 코드와 비중을 직접 입력·추가·삭제. 검색창에서 고른 종목은 **＋ 구성에 추가** 버튼으로 넣을 수 있습니다. 비중 합계가 100%가 아니면 경고가 뜨고 실행 버튼이 잠깁니다. **⚖️ 비율은 유지하고 합계만 100%로 맞추기** 버튼으로 한 번에 고칠 수 있습니다.
- **예시 포트폴리오** (`PORTFOLIO_PRESETS`): 중립형·안정형·성장형, 클래식 60/40, 올웨더형, 비교용 100% 주식. 2004년 말부터 데이터가 있는 SPY·KODEX 200·IEF·TLT·GLD로 구성해 2008 금융위기도 검증할 수 있습니다.
- **설정**: 리밸런싱(매년/분기/매월/안 함 — 해당 기간 첫 거래일에 목표 비중으로 복귀), 초기 금액, 추가 적립(기본 매년, 매월 선택 가능 — 해당 기간 첫 거래일에 목표 비중대로 분할 매수), 현금 연 이자율, 거래비용(리밸런싱 매매 금액에 부과)
- **결과**: 최종 평가금액, 연환산 수익률(적립 시 XIRR), MDD, 변동성, 샤프, 최악의 해, 리밸런싱 횟수·비용 / 성장 곡선(리밸런싱 vs 안 함 vs 개별 자산, 급락 구간 음영) / 낙폭 그래프 / 비교표 / 연도별 수익률 / 비중 변화 / 급락 구간별 하락률
- 자산마다 상장일이 다르면 **모든 자산의 데이터가 있는 날부터** 계산하고, 시작일을 늦춘 자산을 알려 줍니다.
- 미국 자산은 원화 환산(환율 변동 포함), 소수 단위 매매를 가정합니다.

### 적립식 투자 (Streamlit 버전)

사이드바 **투자 방식 → 적립식**을 고르면, 매월(또는 매년) 첫 거래일 종가로 정해진 금액만큼 사서 팔지 않고 끝까지 보유하는 **매수 후 보유** 전략으로 계산합니다(전략 고정).

- 설정: 적립 주기(매월/매년), 회당 금액, 시작할 때 일시금(선택), 거래비용
- 1주 단위로 사고 남은 돈은 다음 매수로 이월합니다(지수는 소수 단위). 매매 전략은 적용하지 않습니다.
- 결과: 총 투자원금, 최종 평가금액, 총 손익, 누적 수익률, **연환산 수익률(XIRR, 돈이 들어간 시점 반영)**, 같은 총액을 첫날 넣은 거치식과 비교, 최저 평가손익률, 평균단가
- 그래프: 원금 vs 평가금액(급락 구간 음영, 로그 스케일), 평균단가 vs 주가, 매수 내역
- **적립 시작 시점별 분석**: 1·3·5·10·20년 적립을 기간 안의 모든 시작 시점에서 했을 때 수익률 분포와 손실 확률, 같은 기간 거치식과 비교

### 기간 바로가기 · 급락 구간 (Streamlit 버전)

- 사이드바 **기간 바로가기**: 최근 3/5/10년, 2000년부터, 1990년부터, 그리고 역사적 급락 구간(IMF, 닷컴 버블, 금융위기, 2011, 중국 폭락, 2018, 코로나, 2022 금리 인상, 2024 엔캐리 청산, 2025 관세 충격)을 고르면 위기 전부터 회복기까지 날짜가 자동으로 들어갑니다.
- 자산 곡선에 급락 구간(고점~저점, 대략)이 주황 음영으로 표시되고, **급락 구간별 성과** 표에서 전략과 단순 보유의 낙폭·회복 시점을 비교합니다.
- 날짜를 직접 바꾸면 바로가기는 '직접 선택'으로 돌아가고, 결과가 있는 상태에서 바로가기를 고르면 새 기간으로 자동 재계산합니다.
- 급락 구간 목록은 `backtest_core.py` 의 `CRISES` 에서 고칠 수 있습니다.

### 투자기간 분석 (Streamlit 버전)

| 탭 | 내용 |
|---|---|
| 보유기간별 | 기간 안의 모든 날짜에 샀다고 가정하고 1개월~10년 보유했을 때 수익률의 평균·중앙값·최저·최고, 플러스 확률, -10% 이상 손실 확률 (전략 vs 단순 보유) |
| 연도별 | 달력 기준 연도별 수익률 비교 |
| 매수 시점별 | 매수일에 따라 같은 기간(예: 1년) 보유 수익률이 어떻게 달랐는지 그래프, 플러스 확률, 전략이 더 나았던 비율 |

- 긴 보유기간을 보려면 시작일을 충분히 앞당기세요(시작일이 20개 이상 나오는 보유기간만 표시).
- 전략의 기간별 수익률은 전체 자산 곡선에서 잘라 계산한 값이라, 그 날짜에 전략을 새로 시작한 결과와는 조금 다를 수 있습니다.

결과: 수익률 · 단순 보유 대비 · 연환산 · MDD · 승률 · 샤프 지수, 자산 곡선, 거래 내역, backtesting.py 상세 차트(캔들·매매 시점·지표)

### 검색 가능한 종목

| 구분 | 범위 | 예시 검색어 |
|---|---|---|
| 국내 주식 | KOSPI·KOSDAQ 전 종목 | `현대차`, `005380` |
| 국내 ETF | 상장 ETF 전체 (네이버 목록, 실패 시 `KR_ETFS` 주요 ETF) | `코스피200` → KODEX 200, `나스닥100` → TIGER 미국나스닥100, `S&P500` |
| 지수 | 코스피·코스피200·코스닥, 나스닥100·나스닥종합·S&P500·다우·러셀2000·필라델피아 반도체 (`INDICES`) | `코스피 지수`, `나스닥100 지수`, `KS11` |
| 미국 ETF | 주요 40여 개 (`backtest_core.py` 의 `US_ETFS`) | `QQQ`, `SPY`, `나스닥100`, `반도체` |

- 검색창은 **자동완성**: 글자를 칠 때마다 후보가 뜹니다. 띄어 쓴 단어가 모두 들어간 종목을 찾습니다(예: `tiger 나스` → TIGER 미국나스닥100).
- `코스피200`, `나스닥100`, `S&P500`, `sp500` 처럼 띄어쓰기·기호가 달라도 찾아지도록 별칭(`ALIASES`)을 붙였습니다.
- 목록에 없는 종목도 **6자리 종목코드** 또는 **미국 티커**(예: `TSLA`)를 입력하면 바로 백테스트할 수 있습니다.
- 국내 종목 시세는 네이버 → 야후(`.KS`/`.KQ`) 순서로 시도합니다. 해외에 있는 Streamlit Cloud 서버에서 네이버가 막혀도 야후로 받아옵니다.
- 미국 종목은 달러 가격을 **일별 원/달러 환율로 원화 환산**해 계산합니다. 그래서 수익률에 환율 변동이 포함되고, 초기 자금도 원화 기준입니다.
